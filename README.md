# hexlock

Локальный менеджер паролей для Windows 10/11. Хранит записи в зашифрованном файле и заполняет формы через расширение для Chrome, Edge и Firefox.

Лицензия: [MIT](LICENSE).

Текущая версия: 0.7.0. Десктопное приложение рассчитано на Windows; поддержка Linux и macOS не реализована. Проект не проходил независимый аудит безопасности.

## Запуск

Откройте `hexlock.exe`. При первом запуске задайте мастер-пароль: минимум 8 символов. Для защиты файла лучше использовать длинный уникальный пароль. Для готовой сборки нужен Windows с WebView2; Python устанавливать не требуется.

В комплекте один EXE. Этот же файл работает как приложение, помощник расширения и средство регистрации в браузере. При обычном запуске открывается окно хранилища, при обращении браузера работает обмен сообщениями без окна.

## Возможности

- Разделы по сайтам со всеми аккаунтами внутри, поиск по сайту и логину.
- Добавление, редактирование и удаление записей.
- Генератор паролей.
- Копирование с очисткой буфера через 20 секунд.
- Блокировка при сворачивании окна и после пяти минут без операций с хранилищем.
- Импорт CSV, TSV и TXT из браузера.
- Экспорт всех записей в CSV, TSV и TXT.
- Кнопка показа пароля в полях ввода и уведомления о копировании.
- Локальная проверка повторяющихся паролей и паролей короче 12 символов.
- Заполнение логина и пароля по точному домену с подтверждением в приложении.
- Светлая и тёмная тема по настройкам системы.

## Проверка паролей

Нажмите «Проверка» в открытом хранилище. В отдельном разделе появятся аккаунты с одинаковыми паролями и паролями короче 12 символов. Повторяющиеся пароли отмечены красным. «Изменить» открывает выбранный аккаунт, «К записям» возвращает обычный список. Сначала смените пароль на самом сайте, затем сохраните новый в hexlock.

Проверка выполняется локально. Интерфейс получает только ID записей и признаки проблем, без паролей и их отпечатков. Результаты очищаются при блокировке и обновляются после изменений. Это не поиск по базам утечек, не оценка энтропии и не гарантия стойкости пароля.

## Расширение

Сначала положите `hexlock.exe` в постоянную папку. Регистрация сохраняет путь к нему; если переместите файл, повторите регистрацию.

### Chrome и Edge

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите режим разработчика и загрузите папку `extension/chromium` из комплекта.
3. Скопируйте ID расширения и выполните одну из команд в PowerShell из папки с EXE:

```powershell
.\hexlock.exe --register chrome --extension-id ВАШ_ID
.\hexlock.exe --register edge --extension-id ВАШ_ID
```

Появится сообщение о регистрации. Права администратора не нужны.

### Firefox

Откройте `about:debugging`, выберите «Этот Firefox» и загрузите временное дополнение из `extension/firefox/manifest.json`. Затем выполните:

```powershell
.\hexlock.exe --register firefox
```

Временное дополнение исчезает после перезапуска Firefox. Для постоянной установки нужна подписанная сборка расширения.

### Заполнение

Перезапустите браузер после регистрации. Откройте приложение, нажмите правой кнопкой в поле логина или пароля на HTTPS-странице и выберите «Вставить из hexlock». Выберите запись и подтвердите передачу в приложении.

Если хранилище заблокировано, введите мастер-пароль в приложении и повторите действие в браузере. Пароль не вводится в страницу или расширение.

Расширение работает только в основном документе страницы. Iframe исключены. Поддомены считаются разными сайтами: запись для `example.com` не выдаётся `login.example.com`.

Соединение использует Native Messaging и локальный named pipe. HTTP-сервер и сетевой порт не запускаются. Форматы запуска описаны в документации [Chrome](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging) и [Firefox](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Native_messaging).

## Импорт

Разблокируйте хранилище и нажмите «Импорт». Поддерживаются CSV, TSV и TXT с заголовком и колонками сайта, логина и пароля. Разделитель: запятая, точка с запятой или табуляция. Заголовки могут быть `url`, `username`, `password`, `site`, `login`, `domain` или их русские варианты.

Перед сохранением показывается количество новых записей, дублей и пропущенных строк. Дубль означает полное совпадение сайта, логина и пароля. Другой пароль того же аккаунта сохраняется отдельной записью, без замены старого. Одинаковые пароли разных аккаунтов не считаются дублями. При ручном добавлении полная копия тоже не создаётся. Изменившийся после предпросмотра файл не импортируется. Ограничения: 10 МБ и 10 000 строк. Произвольный текст без колонок не поддерживается.

Причины пропуска и номера первых 20 проблемных строк показываются в окне импорта. Пустой логин допустим, пустой пароль нет. HTTP/HTTPS-адреса с путём и портом преобразуются в домен. Адреса приложений вроде `android://` сохраняются для ручного выбора и не участвуют в браузерном заполнении. Если URL пуст, берётся название из колонки `name` или `title`; без названия запись попадёт в раздел «Без сайта». Поддерживаются IP-адреса, localhost и колонки `login_uri`, `login_username`, `login_password` из табличного экспорта Bitwarden.

Экспорт браузера содержит пароли открытым текстом. После проверки импорта удалите исходный файл и очистите корзину. Это не стирает копии из облака, резервных копий или старых блоков SSD.

## Экспорт

В открытом хранилище нажмите «Экспорт», выберите CSV, TSV или TXT и подтвердите сохранение. CSV разделяется запятыми, TSV и TXT табуляцией. Колонки: `name`, `url`, `username`, `password`. Экспорт можно импортировать обратно.

Это незашифрованные файлы. Открывайте их как текст: таблицы могут интерпретировать значения, начинающиеся с `=`, как формулы. Экспорт сохраняет исходные пароли без изменений.

## Другие приложения Windows

Пока hexlock открыт, правый клик по стандартному парольному полю Windows класса Edit показывает меню «Вставить из hexlock». Выберите аккаунт и подтвердите передачу в указанную программу. Вставляется пароль; логин можно скопировать из окна хранилища. Если хранилище закрыто, меню предлагает открыть его для разблокировки.

Поддержка зависит от поля ввода. Собственные элементы Electron, Java, Qt и других приложений могут не распознаваться. Программы, запущенные от администратора, могут отклонять вставку. Для таких случаев используйте копирование вручную. В браузере используйте расширение: оно проверяет домен страницы.

В десктопной программе нет надёжной проверки домена. Выбор аккаунта выполняется вручную, а подтверждение показывает путь к программе-получателю. Наличие парольного поля не доказывает, что программа заслуживает доверия. Для вставки используется временный буфер, который очищается сразу после передачи.

## Хранилище и сброс

Файл находится в `%LOCALAPPDATA%\Kluch\vault.json`. Закройте приложение перед копированием. Для переноса на другой компьютер нужны этот файл и мастер-пароль. Копия файла остаётся зашифрованной.

Если пароль забыт, нажмите «Забыли мастер-пароль?», задайте новый пароль дважды и введите `СБРОС`. Старое хранилище заменится пустым без резервной копии. Прежние записи после сброса вернуть нельзя.

Путь `%LOCALAPPDATA%\Kluch` сохранён для совместимости с предыдущими версиями. Смена названия на hexlock не переносит и не сбрасывает данные. Обычное удаление и замена файла не гарантируют физического стирания старых блоков SSD или внешних резервных копий.

## Исходники

Нужны Python 3.12 и Windows с WebView2.

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install .
.venv\Scripts\python.exe app_launcher.py
```

Структура проекта:

```text
app/             хранилище, криптография, интерфейс и локальная связь
native_host/     протокол Native Messaging и регистрация в Windows
extension/       расширения Chrome, Edge и Firefox
app_launcher.py  выбор режима запуска
```

Зависимости: `cryptography`, `argon2-cffi`, `pywebview`. Секреты и внешние сервисы для запуска не требуются.

Файл `.env` не нужен: здесь нет API-ключей, серверных учётных данных и удалённого сервиса. Мастер-пароль задаётся в приложении, а не в конфигурации.

Исходные папки расширений содержат только манифесты, общий код находится в `extension/common/background.js`. Для загрузки расширения используйте папки `dist/extension/chromium` и `dist/extension/firefox`, которые создаёт сборка.

## Сборка

```powershell
.venv\Scripts\python.exe -m pip install ".[build]"
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --icon NONE --name hexlock --add-data "app/ui;app/ui" app_launcher.py

foreach ($browser in 'chromium', 'firefox') {
    New-Item -ItemType Directory -Path "dist/extension/$browser" -Force | Out-Null
    Copy-Item "extension/$browser/manifest.json", 'extension/common/background.js' "dist/extension/$browser"
}
Copy-Item README.md, LICENSE dist
```

Выполните команды из корня проекта. Они установят PyInstaller и создадут `dist/hexlock.exe`, `dist/extension`, README и лицензию. Интерфейс и Python входят в EXE. Расширение устанавливается браузером отдельно из своей папки.

После изменений проверьте создание и повторное открытие хранилища, неверный пароль, операции с записями, импорт, очистку буфера и блокировку. Для расширения проверьте свой домен, чужой домен, iframe и заблокированное приложение. Сброс проверяйте на отдельном профиле с ненужными записями.

Для проверки без доступа к основному хранилищу запустите приложение в отдельной папке данных:

```powershell
$env:LOCALAPPDATA = Join-Path $env:TEMP 'hexlock-dev-profile'
.venv\Scripts\python.exe app_launcher.py
```

Выполняйте эту команду в отдельном окне PowerShell. После его закрытия переменная в остальных окнах не изменится. Файлы этого профиля остаются на диске до удаления. Автоматизированный набор тестов в репозиторий не включён.

## Публикация и изменения

В Git загружайте исходники, `README.md`, `LICENSE`, `pyproject.toml` и `.gitignore`. Содержимое `dist` можно приложить к GitHub Release отдельно. Не добавляйте хранилище, экспорт паролей, виртуальное окружение и временные файлы.

В issue с ошибкой укажите версию hexlock, версию Windows, браузер и шаги воспроизведения. Для примеров импорта используйте вымышленные аккаунты. Перед отправкой скриншота скройте логины и адреса личных сервисов. Если ошибка позволяет получить чужие пароли, сначала сообщите автору приватно, без публикации секретов и рабочего способа атаки в открытом issue.

## Защита и ограничения

Пароли хранятся локально и шифруются AES-256-GCM. Ключ создаётся из мастер-пароля через Argon2id. Мастер-пароль на диск не записывается. Телеметрии нет.

- Используйте длинный уникальный мастер-пароль. Если забудете его, восстановить записи нельзя.
- Расширение заполняет только точный домен и запрашивает подтверждение в приложении.
- CSV, TSV и TXT содержат пароли открытым текстом. Менеджеры буфера обмена тоже могут сохранять скопированные пароли.
- Вирус на компьютере может украсть пароль из памяти или при вводе. Шифрование файла от этого не защищает.
- Независимого аудита безопасности пока не было.
